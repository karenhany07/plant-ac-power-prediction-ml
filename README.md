# Solar Power Generation Forecasting & Deployment ☀️⚡

An end-to-end Machine Learning task developed as part of the **NTI** training program. The project predicts AC Power Generation from solar plants using historical weather sensor data and deploys the trained model via a Flask Web Application.

## 🛠️ Tech Stack
* **Language:** Python 🐍
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn
* **Deployment:** Flask, HTML, CSS

## 📊 Models Trained
* Linear Regression
* Support Vector Machines (SVM)
* Random Forest Regressor
